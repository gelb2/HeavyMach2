# 원본 포팅 실행기의 외부 코드

- touchHLE 계열 실행기: `runtime.json`의 저장소·커밋을 고정한다. 원본 Rust 소스와 수정 패치의 MPL-2.0 표기를 유지한다. `heavymach2.patch`는 이 실행기의 수정 소스다.
- SDL2 및 Rust SDL 연결: 실행기에 포함된 SDL과 별도 고정한 `touchHLE/rust-sdl2`를 사용한다. 원본 라이선스와 저작권 표기를 유지한다. 전체 의존성·라이선스는 고정한 Cargo.lock 및 각 vendor 원본에 있다.
- HeavyMach 1의 공개 호환 패치를 출처와 커밋으로 기록하고 HM2 전용 공간에서 적용했다. 다른 게임 checkout을 빌드 입력이나 출력으로 연결하지 않는다.
- HeavyMach 2 원작 IPA·실행파일·그림·음향·게임 데이터의 권리는 원작 권리자에게 있다. 이 저장소의 자체 코드 라이선스를 원작 자료에 적용하지 않는다. 원본과 이를 포함한 앱은 로컬 검증용이며 저장소·사이트에 게시하지 않는다.
