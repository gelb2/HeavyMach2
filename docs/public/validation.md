## 공개 클론에서 빌드와 실행

새 클론에서 공통 코어 검사 29개를 통과했다. 공개 PWA에서 내려받은 파일의 SHA-256을 검증하고 캠페인 자원 1,576개를 준비했다. 기존 배포 준비 자원과 비교한 결과 모든 파일의 바이트가 일치했다. 같은 클론에서 iOS·Android·PWA·Mac을 빌드했다. [재현 명령](build-and-install.md#소스-받기)

| 플랫폼 | 직접 확인한 범위 |
| --- | --- |
| iOS | 정식·치트 Release를 iOS·iPadOS 26.5 시뮬레이터에 설치하고 정식판을 실행했다. 일반 앱의 Debug UI 검사에서 iPhone의 전장 이동·경로 교체·더블탭 점프, iPad의 이동·임무·인벤토리·일시정지와 재개를 확인했다. Release 치트판은 두 시뮬레이터에서 화이트마운틴 포털 14경로를 각각 통과했다. [iOS UI 검사 코드](../../Apple/UITests/WorldInputTests.mm) |
| Android | ARM64·x86-64 일반·치트 Debug를 빌드했다. ARM64 에뮬레이터에서는 두 앱을 설치하고 일반판에서 슬롯을 만들어 Ruin Field로 들어갔다. 치트판으로 설원 포털·보스·레이저 공습 구매·공습 피해 27개 조건을 통과했다. |
| PWA | 정식·치트 Wasm을 빌드하고 Mac Chrome의 독립 앱으로 설치했다. 오프라인 재실행과 저장 유지, 치트판 상점 왕복과 효과음 재생을 확인했다. |
| Tauri Mac | 두 번들의 로컬 서명을 확인했다. 정식판에서 새 슬롯으로 기지와 전장에 들어가 이동했고, 재실행 뒤 슬롯이 남았다. 치트판은 별도 검증 슬롯에서 기지에 들어갔다. |

## 원본 대조와 이전 실행

일반판 iPhone·HD iPad의 [차이 조사와 유니버설 설계 보강](../universal-design-audit-results-20261113.md)을 추가했다. 패키지·픽셀·원본 함수·현재 소스의 정적 비교이며, 새로운 앱 실행·유니버설 구현·기기 설치 결과가 아니다.

## 실제 iPad의 정식판

사용자는 첫 미션 부근의 이동·전투·여러 이동 경로 그리기, 퀘스트 수락·성공을 확인했다. 스카이베이스에서 몇몇 임무를 완수했고 전투·아이템 획득·스킬을 사용했다. 필요한 물품을 이미 보유한 임무를 수락한 뒤 다시 확인하면 완료 조건을 충족하는 동작도 원작과 같다고 확인했다.

2026년 11월 12일에는 Wasteland까지 진행한 시점에 크래시를 발견하지 않았다고 보고했다. 지역별 전체 임무와 최종 캠페인을 모두 검사한 결과는 아니다. [사용자 플레이 원문과 설치 기록](../ipad-release-installation-20261111.md)

탭투스타트 일러스트 아이콘을 포함한 일반 Release를 실제 iPad에 갱신 설치했다. 원작 준비 자원 1,479개와 패키지 파일의 해시가 일치했고, 기존 저장 28,204바이트를 보존했다. 새 아이콘·앱 시작·타이틀·프로세스 유지를 확인했다. 같은 기록에서 실제 iPad의 치트 앱 설치는 수행하지 않았다. [2026-11-12 패키지·기기 기록](../evidence/title-illustration-icons-20261112.json)

## iPad 시뮬레이터의 치트판

2026년 11월 12일, iPad Air 11-inch (M4)·iPadOS 26.5의 별도 치트 앱에서 확인한 값이다.

| 항목 | 해당 실행의 결과 |
| --- | --- |
| 동시 조건 | 115개, 공통 프레임 구간에서 갱신 |
| 실행 길이 | 1,200프레임 |
| 실제 발사한 무기 정의 | 110종 |
| 동시에 진행한 효과음 | 최대 26개 |
| 생성한 효과음 컨텍스트 | 1개 |
| 메뉴 버튼 실패 | 0 |
| 예열 뒤 자원 재읽기·존재 확인 실패 | 0 |
| 예열 뒤 이미지 텍스처 재업로드 | 0 |

조건에는 무기·전투·구급상자·공습·전장·대시·BOT·메뉴·도움말·게임오버·랭킹 이용 불가 안내·완료 임무가 포함된다. 같은 게임 코어의 여러 상태를 함께 실행한다. 서로 배타적인 화면은 독립 상태로 분리하며, 한 상태에서 원작의 전투 정지 규칙을 없애지 않는다.

이 실행은 모든 임무·아이템·전투 분기의 검증 완료를 뜻하지 않는다. `completeGameCoverage`도 `false`로 기록돼 있다. [실행 명세](../evidence/title-illustration-icons-20261112.json) · [공통 코어 70개와 GPU·음향 2개 검사의 이전 기록](../evidence/app-icons-validation-20261111.json)

## 현재 플레이에서 유의할 문제

| 항목 | 상태와 다음 확인 |
| --- | --- |
| E-10 격파 과제의 달성 효과음·토스트 | 사용자 제보. 조건 갱신부터 UI·음향 출력까지 재현·수정해야 한다. |
| “크롬 10개 모아오기” 등 아이템 지급 | 지급 누락 의심. 수락 때 받는 물품·현장 수집·완료 보상·알림을 구분해 전수 확인해야 한다. |
| 일부 HUD·UI·사거리 안내 | 기존 제보와 후속 수정 기록이 함께 있다. 전체 화면 목록과 현재 설치본을 대조하는 최종 검사가 남는다. |
| 시뮬레이터 게임오버 전환 성능 | 이전 iPad 검사에서 15초 기준에 16.07초로 실패했다. 기능·프레임 검사 통과와 별개이며 실기기 전체 성능으로 확대하지 않는다. |
| 랭킹 | 현재 서비스에 연결하지 않는다. “현재 랭킹 서비스를 이용할 수 없습니다.”를 표시한다. |

## 남은 검증

- 전체 임무 60개와 수집·격파·보상·저장 분기, 모든 지역과 최종 캠페인.
- 하체 장비 23종의 보행·애니메이션, 전체 BOT 전투·수집·수리·사망 결과.
- 후속 연결한 임무용 아이템·적 배치의 동시 치트 시나리오와 최종 대조.
- OS 음향 중단·출력 경로 전환과 복귀, 장시간 플레이.
- 같은 iPad의 HD 포팅판·정식판·치트판을 사용하는 최종 일괄 대조. 코드 흐름·자원 로드·그림·입력·음향·진행·저장 결과를 함께 확인한다.
- 기기별 추가 검증은 [플랫폼 현황](../canonical.md#플랫폼과-검증-현황)과 [TODO](../todo.md)의 미완료 항목을 따른다.

[작업 순서](../validation-build.md#작업-순서)에 따라 전체 구현과 동시 검사 구성을 갖춘 뒤 마지막 단계에서 원작을 일괄 대조한다. 기능 하나를 구현할 때마다 포팅판 실행을 반복하지 않는다. iPhone을 HD판 정상동작 판정에 사용하지 않는다.
