# HeavyMach 2 플레이 방법

[README](../../README.md) · [빌드와 설치](build-and-install.md) · [현재 검증 범위](validation.md)

일반 플레이에는 **HM2 Source**를 사용한다. 현재 iPad는 세로 화면이고 한국어를 기본으로 표시한다. `TEST` 아이콘의 **HM2 Validation**은 여러 조건을 자동으로 검사하는 별도 앱이다.

## 시작과 이어하기

1. HM2 Source를 열고 탭투스타트 화면을 터치한다.
2. 저장 슬롯을 선택하고 `OK`를 누른다. 빈 슬롯은 이름을 입력해 새로 시작한다. 이름은 1~10자다.
3. 기존 슬롯은 저장한 기지나 전장에서 이어서 시작한다. `DEL`은 선택한 저장을 삭제하는 기능이므로 이어하기에는 사용하지 않는다.

## 기지와 임무

기지의 시설을 한 번 터치하면 선택·설명을 표시하고, 선택한 시설을 다시 터치하면 들어간다. 사령부에서 임무를 선택해 내용을 펼치고 `ACCEPT`로 수락한다. 상점에서는 아이템을 선택한 뒤 가격·수량을 확인해 구매하거나 판매한다. 정비와 인벤토리에서 보유 장비를 확인한다.

기지의 출구를 선택해 전장으로 나간다. 조건을 충족한 임무는 지정된 기지의 사령부에서 보고하고 완료 결과창을 확인한다. 필요한 물품을 이미 충분히 보유한 상태에서 임무를 받으면, 다시 확인할 때 완료 조건이 충족될 수 있다. 사용자가 스카이베이스에서 원작과 같은 동작으로 확인한 경로다.

## 이동과 전투

| 입력 | 동작 |
| --- | --- |
| 지면 터치 | 해당 지점을 향해 이동한다. |
| 지면에서 손가락으로 경로 그리기 | 여러 이동 지점을 차례로 지정한다. |
| 적 터치 | 적을 표적으로 선택한다. 장착 무기는 표적·사거리·발사 간격 조건에 따라 공격한다. |
| 적을 선택한 채 다른 적까지 드래그 | 추가 표적을 선택한다. |
| 지면 두 번 터치 | SP와 현재 상태가 대시 조건을 만족하면 대시한다. |
| 하단의 좌·우 무기 아이콘 | 해당 무기의 교체 목록을 연다. |
| 퀵슬롯 아이템 | 선택한 아이템의 사용 규칙을 적용한다. 수리·공습처럼 대상 지정이 필요한 아이템은 전장에서 대상을 터치한다. |

무기 아이콘은 좌우 무기 선택에 사용한다. `OUT OF RANGE`가 계속 보이면 표적 선택과 무기 사거리를 확인한다. 사거리 내에서도 표시가 유지된다는 제보는 [TODO](../todo.md)에 남아 있으며, 표시만 보고 적이 없거나 공격할 수 없다고 단정하지 않는다.

전장의 인벤토리·임무·시스템 메뉴를 열면 전투가 멈춘다. 창을 닫고 재개한다. 지역 이름이 표시된 이동 구역은 연결된 기지·전장으로 이동하는 데 사용한다. 시스템 메뉴에는 도움말과 저장 후 나가기 경로가 있다.

## 저장과 앱 갱신

진행 저장은 슬롯 생성·선택과 게임의 저장/전환 경로에서 처리한다. 전투 중 아무 시점의 앱 강제 종료를 수동 저장처럼 사용하지 않는다. 일반 앱의 파일은 앱 컨테이너 안 `Library/Application Support/HeavyMach2/HeavyMach2.sav`다.

앱을 갱신하거나 서명·앱 ID를 바꾸기 전에는 Xcode의 **Devices and Simulators**에서 데이터 컨테이너를 내려받는다. 앱을 삭제하면 저장도 지워질 수 있다. 같은 앱 ID로 갱신하는 절차와 백업 방법은 [설치 안내](build-and-install.md#실제-ipad에-설치)를 따른다.

## 현재 알려진 문제

- E-10 격파 과제의 조건을 달성해도 효과음과 토스트가 나오지 않는다는 사용자 제보가 있다.
- “크롬 10개 모아오기” 같은 수집 퀘스트의 아이템 지급 여부를 확인해야 한다. 실제 지급 누락과 알림 누락은 아직 구분되지 않았다.
- 전체 임무·캠페인과 원작 최종 일괄 대조는 끝나지 않았다. [검증 범위와 근거](validation.md)

문제를 기록할 때 지역·임무명, 직전에 누른 버튼, 아이템 수량의 전후 값, 설치한 앱 구분을 함께 남긴다. 사용자 저장은 별도로 보관한다.
