## 원본 동작과 비교

일반판과 HD판의 표, 그림, 함수와 실행 화면에서 원본의 동작을 조사했다. iPhone의 메뉴와 배치는 일반판을, 캠페인과 공통 게임 규칙은 HD판을 중심으로 대조했다. 같은 저장과 입력으로 사령부 보상을 확인했을 때 원작 HD와 복원판에서 80 Cr과 100 Cr이 차례로 들어왔다. 전체 캠페인과 최종 HD 일괄 대조는 남아 있다. [사령부 비교](../command-detail-restoration-20261111.md) · [기능별 근거](../feature-verification.md)

## 치트판에서 시작 조건 준비

레벨·장비·임무·위치를 바로 설정해 반복 검사를 한다. 시작 조건을 준비한 뒤 이동, 사격, 피격, 거래와 저장은 공통 코어에서 실제로 실행한다. iPhone·iPad 시뮬레이터의 기본 검사는 각각 126조건을 실행했다. 화이트마운틴 포털 14경로, 보스 의뢰 4건과 장비 29조건은 별도 검사로 확인했다. [치트판 빌드와 결과 파일](build-and-install.md#치트-앱-실행과-결과) · [설원 결과](../white-mountain-implementation-20261119.md)

## 일반 앱과 실제 입력

사용자가 직접 플레이하며 경로를 바꾼 뒤 점프가 동작하지 않는 경우, Skyway 떨림, 상점의 빈칸 표시와 레이저 공습 누락을 발견했다. 수정 뒤 iPhone의 실제 OS 터치 입력으로 경로를 다시 그려 두 번 탭했다. iPad에서는 저장을 열어 전장에서 이동하고, 임무와 인벤토리, 일시정지와 재개를 확인했다. 정식 앱의 실기기 플레이와 시뮬레이터의 자동 검사는 각각 기록했다. [iPhone 재현과 수정](../iphone-module-audit-20261118.md) · [공개 클론 검사](validation.md#공개-클론에서-빌드와-실행) · [사용자 플레이](gameplay-gallery.md)

## 설치 상태와 성능

웹 탭, 설치형 PWA와 Tauri 창은 실행 조건이 다르다. 갤럭시에서는 설치 아이콘으로 실행하고, 홈 화면으로 나갔다 돌아온 뒤 가로 화면과 배경음이 이어지는지 확인했다. Mac Chrome 설치판은 오프라인 재실행과 저장 유지까지 검사했다. 그림이나 효과음 자원을 반복 생성하는지도 별도로 관측했다. 실기기 장시간 프레임·발열, Safari 설치판의 오프라인 재시작, 반대쪽 가로 회전은 남아 있다.
