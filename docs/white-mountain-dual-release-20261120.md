# 화이트마운틴 출구·보스 수정과 실기기 설치

화이트마운틴 기지에서 Desert 01과 SnowPass로 나갈 수 있다. Desert 01 포털 3번과 SnowPass의 귀환 포털은 각각 화이트마운틴 기지로 연결된다. SnowPass 반대쪽 포털로 설원 분지에 들어간다.

| 출발 | 일반 입력 | 도착 |
| --- | --- | --- |
| Desert 01 | 북동쪽 포털 3번을 밟는다 | 화이트마운틴 기지 |
| 화이트마운틴 기지 | Desert 01 버튼을 두 번 선택한다 | Desert 01의 포털 3번 안쪽 |
| 화이트마운틴 기지 | Snow Pass 버튼을 두 번 선택한다 | 첫 설원 전장 SnowPass |
| SnowPass | 귀환 포털을 밟는다 | 화이트마운틴 기지 |
| SnowPass | 전장 안쪽을 가로질러 반대쪽 포털을 밟는다 | SnowBasin |

두 출구는 원작 `Button` 행과 선택·터치 경로를 사용한다. 일반과 선택 상태를 256×64 이미지 한 장에 담았다. 안내 글자는 필드 포털에 쓰는 Trebuchet 굵은 이탤릭으로 준비했다. 설원 지역명과 포털의 게임 내 표시는 기존 공통 렌더러를 사용한다.

보스 05~08은 맵 중앙부의 (0, 70)에 놓았다. 양쪽 진입점에서 이 지점까지 약 430단위다. 의뢰를 수락하고 240단위 이내로 이동하면 기존 보스 생성기가 작동한다. iPhone·iPad 치트 앱에서 각각 포털 14방향과 보스 의뢰 4건을 통과했다. 보스가 진입 직후 등장하지 않고 접근 뒤 나타나는 것과 실제 전투·격파·보상 저장을 확인했다. 시작 거리를 제한하지 않은 기존 생성기의 동작과 새 반경 경계를 호스트에서 검사했다.

## 프로필과 설치

iPad Air 13형의 Lv22 프로필과 각 기기의 기존 저장을 백업했다. iPad 저장 사본에 Base005·Base006·화이트마운틴의 방문 기록을 더해 여섯 기지 방문을 반영했다. 기존 임무, 레벨, 장비, 초기 위치는 iPad 저장을 따랐다. 변경 전후 프로필로 각 사령부의 임무 목록을 비교했다. Lv22 프로필에서 화이트마운틴 첫 보스 의뢰는 기존 Lv28 및 선행 임무 조건을 따른다. 조건을 갖춘 치트 프로필에서 보스 의뢰가 정상 표출되는 것을 확인했다.

두 기기에 서명된 동일 `HeavyMach2Source` Release를 설치했다. 번들 자원 1,576개를 준비본과 대조했다. 설치 직후 기존 저장을 다시 읽어 백업과 같은지 확인한 뒤, 수정한 iPad 저장을 양쪽에 넣고 동일한 파일을 읽어냈다. 두 앱의 시작 화면을 캡처했다. iPhone은 실행 후 별도 저장이 생겼으며 여섯 기지 방문 기록을 유지했다. 그 뒤 해당 파일에는 쓰기를 수행하지 않았다. 실기기는 설치·실행 범위이며, 포털·사령부·보스 검증은 시뮬레이터와 호스트에서 했다.
