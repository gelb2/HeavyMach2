# 포팅판 메크·적·HUD 크기 측정 계획

2026-11-10 사용자 요구. 아직 측정을 완료하지 않았다. 복원판의 표시 배율과 HUD 배치를 확정하기 전에 수행한다.

## 비교 대상

- 일반판 원본을 사용하는 iPhone 포팅판과 HD 원본을 사용하는 iPad 포팅판을 각각 측정한다. HD를 iPhone에서 실행한 시험판은 추가 비교이며 일반판의 측정을 대신하지 않는다.
- 각 실행의 IPA 버전·해시, 실행기 커밋/패치·실행파일 해시, 기기 모델·OS·화면 방향·창 크기를 기록한다. 일반판 후보 2.0.1과 비교용 1.1.0, HD 후보 1.0.3과 비교용 1.0.0의 측정값을 서로 합치지 않는다.
- 현재 일반판 오류 조사는 중단 상태다. 보존된 정상 표시 장면에서 측정 가능한 항목부터 기록한다. 표시 오류·가림·실행 미확인 때문에 측정할 수 없는 항목은 미측정으로 남긴다. 숫자를 채우기 위해 원작이나 호환 계층의 표시 배율을 바꾸지 않는다.
- 원작 방향·배치 상태를 먼저 측정한다. 가로 시험판과 최종 복원판은 별도 열로 대조한다. 호환 실행기의 viewport·회전·배율을 코드와 실행 로그로 확인하지 못한 값은 포팅판 관측값이며 원작 표시가 정확히 재현됐다는 증명으로 취급하지 않는다.

## 장면과 측정 단위

같은 맵 위치, 주인공 Body/Foot/무장 ID, 적 종류·ID, 방향·애니메이션 상태, 카메라 위치·배율을 맞춘다. 양쪽에 없는 유닛은 공통 비교에서 제외하고 해당 판본의 별도 항목으로 기록한다. 정지 장면과 이동·발사 장면을 구분하며 애니메이션 크기 변화는 최소·최대 및 프레임 근거를 남긴다.

원본 해상도의 캡처를 사용한다. 시뮬레이터 창의 데스크톱 확대율을 게임 크기로 측정하지 않는다. 캡처 전체 크기, 실제 게임 viewport, 검은 여백, 안전 영역을 따로 기록한다. 게스트 논리 좌표→호스트 논리 좌표→출력 픽셀의 변환과 Retina 배율도 기록하며 확인되지 않은 좌표계 사이의 값을 추정 변환하지 않는다.

| 대상 | 측정 항목 |
|---|---|
| 주인공 메크 | 조립된 메크의 보이는 폭·높이, 몸체·다리·무장 각각의 폭·높이, 접합점 상대 위치, 화면 점유율 |
| 적 유닛 | 종류·ID별 보이는 폭·높이와 화면 점유율, 같은 장면의 주인공 대비 크기 비율. 한 적의 값으로 전체 적을 대표하지 않음 |
| HUD 전체 | 표시 영역의 위치·폭·높이, 화면 대비 폭·높이, 전장 가림 영역. 전체 바깥 사각형과 실제 표시 요소가 차지하는 영역을 구분 |
| HUD 요소 | 체력·경험치·재화·장비·버튼 등 실제 존재하는 요소별 위치·폭·높이, 글자 표시 높이, 간격과 가장자리 거리 |
| 입력 영역 | 버튼 그림과 실제 터치 판정 영역을 별도로 기록. 이미지 경계로 터치 영역을 추정하지 않음 |
| 전장 | 카메라가 보여주는 월드 폭·높이, 비교 기준 지형의 크기, 화면비와 메크 대비 지형 비례 |

보이는 유닛 경계는 투명 여백·그림자·탄환·연기·HP 표시를 제외한 조립 본체를 기준으로 한다. 무장은 본체 측정에 포함하고 파츠별 수치도 남긴다. 효과나 다른 유닛에 가려 정확히 구분할 수 없는 프레임은 기준 측정에서 제외한다. 충돌 영역은 별도 항목이며 보이는 경계와 같다고 가정하지 않는다.

출력 픽셀과 확인된 논리 좌표 크기를 함께 기록한다. 화면 점유율은 실제 게임 viewport 대비 폭·높이 비율이며, 면적을 기록할 때는 바깥 사각형인지 실제 표시 면적인지 명시한다. 픽셀 밀도가 다른 기기의 원시 픽셀 수를 바로 비교하지 않는다. 실물 mm와 실제 가독성·조작감은 시뮬레이터 결과로 단정하지 않고, 시뮬레이터 정상동작 검증 후 실기기에서 확인한다.

## 산출물과 완료 조건

1. 판본·기기·장면·유닛 ID별 측정표를 만든다. 캡처 파일/해시·프레임·측정 경계·변환 근거·오차 또는 미확인 사유를 연결한다. 표의 비교 열은 일반판 포팅판, HD 포팅판, 복원판 iPhone, 복원판 iPad로 나눈다.
2. 주인공 기본 장비와 크기가 다른 장비 조합, 적 종류별 기준 장면, HUD 전체 및 요소별 측정을 확보한다. 원본 데이터에서 확인한 대상 목록과 대조해 미측정 항목을 명시한다. 일부 장면만 측정한 상태를 전수 완료라고 하지 않는다.
3. 원작 두 판본의 차이와 호환 계층 오류를 구분한다. 측정값을 근거로 복원판의 기기별 표시 크기·허용 오차를 정하고, 그 기준을 구현 전에 기록한다. 실패한 복원 결과에 맞춰 기준을 바꾸지 않는다.
4. 보고 페이지에 원본 크기 캡처와 경계를 표시한 비교 그림, 수치표를 함께 제공한다. 두 캡처를 같은 너비로 축소한 그림만으로 크기 비교를 대신하지 않는다.

이 측정 계획은 [포팅 앱 검증 계획](reference-port-validation-plan.md)의 표시 비교를 구체화한다. 후속 구현은 [HD 가로 화면 계획](hd-landscape-plan.md)의 iPad 확대 방지·하단 중앙 HUD 조건을 적용한다. 원본 IPA와 사용자 저장은 보존하며 측정만을 위해 같은 빌드를 새로 쌓지 않는다.
