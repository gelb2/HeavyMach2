# iPad 메뉴 배율 회귀 수정 — 2026-11-15

## 원인과 이전 구현

전체 커밋165건의 이력을 조회하고 표시 소비 경로를 변경한27건을 추렸다. 세부 이력과 당시 파일 사본은 로컬 `ipad-menu-fullscreen-20261115/history.json`에 보존한다.

- 기존 iPad 플레이·설치가 확인된 시점: 게임 구현 `4980818`, 원작 제목 일러스트 아이콘을 적용한 `74825d2`. 그때 Apple 호스트는 가변 표시 설정을 전달하지 않았고, renderer가768×1024 논리 화면을 drawable에 균일하게 맞췄다. 당시 iPad11인치 사령부 캡처도 보존돼 있다. 화면 비율 때문에 있던 얇은 상하 여백을 현재 큰 사방 여백과 같다고 취급하지 않는다.
- 회귀 시작: `7622bd1`. 실제 창 크기를 코어에 전달하면서 `DisplayLayout`이 HD 메뉴를 최대1배로 제한했다. 큰 iPad의 허브·상점·사령부가 중앙768×1024에 남았다. 이후 Phone 수정·ExperimentalUI 롤백·원본 배경 선택·버튼 페이지 커밋에서도 이 제한은 남았다.
- 현재 실패 재현: 1024×1366 화면과 안전영역 조건에서 Base001의 그림 영역은 `(128,169,768,1024)`다. 새 회귀 검사는 수정 전 실제 이 범위에서 실패했다. 사용자 제공 Wasteland 캡처와 같은 종류의 큰 사방 여백이다.

11월15일의 실패 캡처끼리 같다는 사실을 과거 정상 iPad와 동일하다는 근거로 사용할 수 없다. 기존 하네스의 iPad18건 FAIL을 알고도 폴백 수정·재검증을 하지 않은 기록을 보존한다.

## 수정

공통 `DisplayLayout`에 HD 메뉴 전용 균일 변환을 추가했다. 실제 화면 크기에 맞춘 하나의 배율을 허브·상점·사령부의 원본 배경, 시설/길 표시, 버튼, 텍스트, 상세/거래 창과 입력 역변환에 함께 적용한다. 원본 그림의 비율과 UV를 유지한다. 검은 패널, 끝 픽셀 늘림, 비등방 확대, 다른 그림, 스크롤을 추가하지 않는다.

상점 아이템 드래그의 drop 좌표도 같은 메뉴 변환을 역산한다. 별도 Apple UI를 만들지 않는다. Phone 배경·배치 경로와 전투·카메라·HUD·저장·음향 코드는 유지한다. 13인치1024×1366에서768×1024 원본의 비율 차이로 생기는 약0.5논리 포인트의 가로 초과분은 화면 경계에서 클립한다. 그림을 변형해 맞추지 않는다.

## 검사와 현재 상태

- 수정 전 회귀 실패와 수정 후 공통 표시·화면 검사2개 통과를 보존했다. HD 메뉴54조건(기지6×화면3×창 크기3)의 전체 화면 배경·균일 비율·같은 입력 역변환을 검사한다.
- 후속 drop 수정 전 두 시뮬레이터에서 선택한 Native 검사8개가 통과했다. 실행 시간 중첩134.846초를 확인했다. 지형 출력, 메뉴→전투→원자 저장 재시작과 Phone720프레임·126상태의 같은 시간 동시 실행을 포함한다. 이를 iPad HD 전체 게임 검증 완료로 확대하지 않는다.
- drop 수정까지 포함한 최종 빌드에서 두 기기의 메뉴 검사도 각각 통과했다. 짧은 검사 구간이 겹치지 않아 병렬 실행기의 최종 집계는 FAIL(overlap0)이다. 이를 숨기거나 같은 시간 검증 통과로 바꾸지 않는다. 최종36캡처의 실제 에셋 하네스와 실제 화면 하네스는 각각36/36 PASS다.
- 최종 후보의 iPad8종 고유 화면을 직접 열고 같은 사령부/상점의 반복 캡처를 화소로 대조했다. 비교54건 중5건은 최대1/255의 GPU 색상 반올림 차이가 있었다. 해당 세 최종 캡처를 다시 직접 열어 확인했다. 나머지 실제 RGBA는 동일했다. 단순 PNG 파일 해시 차이를 화면 차이나 합격으로 추정하지 않았다.
- Native 배경 검사에도 HD 배경 범위·비율·clip 단언을 추가했다. 예전처럼 캡처가 생성됐다는 사실만으로 중앙768×1024 출력을 통과시키지 않는다. 두 독립 하네스의 기존 실패 기준은 완화하지 않는다.
- 실제 기기의 앱과 저장은 이번 수정 작업에서 변경하지 않았다. 아직 병합·정식 설치 완료가 아니다. Native 훅의 자동 호출 미확인도 해소됐다고 주장하지 않는다.
