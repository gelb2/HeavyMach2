# HD 가로 화면 지원 계획

2026-11-09 사용자 지시에 따라 기록한다. 계획이며 아직 구현하지 않았다.

## 현재 근거

확보한 HD 1.0.0과 1.0.3의 게임 화면 회전 함수는 세로 두 방향만 허용한다. 1.0.0의 plist에는 가로도 등록돼 있으나, 두 판본의 포팅판에 가로 시작 옵션을 주어도 세로로 전환됐다. 원본 분석과 시뮬레이터 관측의 세부 범위는 [TODO](todo.md)에 있다. 출시 당시 모든 판본의 동작을 확인한 것은 아니다.

## 보존 조건

- 원본 IPA와 원본 비교용 포팅판의 게임 코드·데이터는 유지한다. 가로 시험판에는 별도 bundle ID와 저장 공간을 사용한다.
- HD 에셋의 해상도, 파츠 조립, 유닛·오브젝트 비례를 유지한다. 가로·세로를 다르게 늘이지 않는다.
- 화면 방향만 바꾸기 위해 원작의 사운드 재생·저장·전투 갱신 절차를 바꾸지 않는다.
- 원작 비교용 호환 실행기와 최종 C++ 공통 코어 복원판의 변경을 구분한다. 호환 실행기 시험 성공만으로 독립 복원을 완료했다고 하지 않는다.

## 구현 순서

1. **가로 출력·입력 확인:** 별도 시험판에서 가로 화면 안에 원작 768×1024 세로 구성을 같은 비율로 표시한다. 좌우 여백을 두고 회전·터치 변환·메뉴 입력을 확인한다. 이 단계는 가로 전체 화면 구성의 완료가 아니다.
2. **게임 영역 확장:** 원작 카메라 좌표·투영·배경 타일 표시 범위를 분석한 뒤 가로 출력 비율에 맞춘다. 화면에 보이는 영역과 적의 생성·활성화·전투 판정 영역을 구분한다. 시야가 넓어져 사거리·스폰·전투 진행이 의도 없이 바뀌지 않는지 검사한다.
3. **UI 배치:** HUD, 슬롯, 기지, 상점·장비·임무 메뉴, 이름 입력창과 키보드를 가로 화면에 배치한다. 화면 크기·안전 영역·터치 좌표를 같은 변환 기준으로 처리한다.
4. **회전과 수명:** 좌우 가로 전환, 세로 복귀, 앱 전환·복귀, iPad 창 크기 변화를 확인한다. 회전 중 저장·장비·임무 상태를 유지한다.
5. **원작 대조:** 같은 저장과 장면에서 원작 세로 기준과 가로 후보의 유닛 비례·파츠 위치·공격·피격·이동·임무·저장 복구·사운드 순서를 대조한다. 화면 밖 적의 활성화 범위도 검사한다.
6. **유니버설 앱 반영:** 검증된 공통 코어와 HD 표시 구성을 iPhone/iPad에 연결한다. 일반판 가로 기준도 별도로 유지해 비교한다. 어느 판본의 콘텐츠를 최종 기준으로 삼을지는 [IPA 전 버전 조사](ipa-version-audit.md)를 참고해 결정한다.

## 완료 기준

아이폰·아이패드 시뮬레이터에서 가로 화면 전체를 사용하며, 이미지 비례와 버튼 입력이 맞고, 메뉴·실제 플레이·진행·저장·음향 검사가 통과해야 한다. 사용자 지시에 따라 포팅판의 시뮬레이터 정상동작 확인 전에는 실기기에 빌드·설치하지 않는다. 이후 실기기 성능과 터치를 확인한다.
