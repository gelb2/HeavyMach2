# 휴대폰 PWA 방향·배경음 검사

## 원인과 수정

공개 `v0.1`을 USB로 연결한 갤럭시에서 설치했다. 앱 아이콘으로 연 독립 창에서 홈 복귀 뒤 384×749 세로 화면이 된 게임을 확인했다. 기존 설치 매니페스트에는 방향 설정이 없었다. 배경음 코드는 홈 화면으로 나갈 때 곡을 끝내고 복귀하면 새 재생 소스를 만들었다.

HeavyMach 1은 설치 매니페스트에 `landscape`를 지정한다. OS가 세로 화면을 주면 게임을 멈추고 가로 안내를 표시한다. HeavyMach 2 휴대폰에도 같은 정책을 적용했다. 기존 앱이 갱신 전에도 새 실행 코드를 받으면 시작·복귀 때 표준 화면 방향 API로 양쪽 가로를 요청한다. 세로 화면에서 시간 진행과 입력을 멈추며, 양쪽 가로의 화면 크기와 안전 영역은 기존 경로에서 계산한다. 태블릿과 데스크톱은 방향 제한이 없는 설치 설정을 사용한다. [HeavyMach 1 WASM PR](https://github.com/gelb2/HeavyMach/pull/24) · [HeavyMach 2 웹 셸](../Web/Shell/app.js)

홈 화면으로 나가면 배경음의 재생 시간과 소스를 유지한 채 오디오 컨텍스트를 정지한다. 복귀하면 같은 소스를 재개한다. 장면이 실제로 다른 곡을 요청하면 새 곡을 재생한다. 효과음은 기존 OpenAL 재생 경로를 사용한다. [배경음](../Web/Shell/audio.js) · [시험](../Web/tests/audio.test.mjs)

변경은 Web 셸·패키징·검사에 들어갔다. 검증에 사용한 정식·치트 Wasm과 게임 데이터는 기존 빌드와 바이트가 같다.

## 갤럭시 설치 앱

공개 `v0.2`의 웹 파일 16개를 HTTPS에서 받아 길이와 SHA-256을 대조했다. 갤럭시 기존 설치 앱에서 새 오프라인 캐시가 활성화됐고, 갱신 전과 같은 28,204바이트 저장을 읽었다. [공개 빌드 기록](https://gelb2.github.io/HeavyMach2/build.json)

Chrome이 관리하는 설치 항목의 방향 설정은 웹 캐시와 별도로 갱신된다. 웹 캐시만 갱신됐을 때 갤럭시 화면은 세로로 돌아왔고 브라우저는 페이지의 방향 잠금 요청을 거부했다. Chrome의 설치 항목 갱신을 요청한 뒤 설치 버전이 1에서 2로 올라가고 방향이 `landscape`로 표시됐다. Android는 앱 창에 양쪽 가로를 허용하는 `SENSOR_LANDSCAPE`를 적용했다. [Chrome의 Android 설치 앱 관리](https://chromium.googlesource.com/chromium/src/+/HEAD/components/webapps/docs/android_architecture.md)

갱신된 설치 앱은 휴대폰 설정을 세로로 둔 상태에서도 755×354 가로로 열렸다. 홈 화면에서 돌아온 실제 전장도 가로였다. 복귀 뒤 배경음 컨텍스트가 재생 중으로 돌아왔고, 마지막 재생 소스에서 시간이 이어졌다. 같은 복귀 동안 새 배경음 소스를 만들지 않았다. 실기기에서 갱신 뒤 확인한 각도는 90도다.

## 홈 화면 전체 화면 개선

휴대폰의 설치 매니페스트에 전체 화면을 지정했다. 기존 Android 설치 앱에서는 원래의 게임 시작 입력으로 브라우저의 전체 화면을 요청한다. Safari 홈 화면은 원작 복원판 HeavyMach 1과 같은 투명 상태바 설정을 사용한다. iPad에서는 Safari가 제공한 표시 영역에서 상하 여백을 게임에 다시 적용하던 부분을 제거했다. 이름과 복구코드 입력 화면은 안전 영역을 유지한다. 공개 정식판의 Wasm, 게임 실행 JS, 에셋은 v0.2와 SHA-256이 같다.

| 환경 | 확인한 화면과 동작 |
| --- | --- |
| iPhone 17 Pro, iOS 26.5 시뮬레이터 | Safari 홈 화면에 설치한 정식판을 가로로 열었다. 타이틀과 기지 화면이 화면을 채웠고, 이름 입력과 슬롯 생성이 동작했다. |
| iPad Pro 13인치, iPadOS 26.5 시뮬레이터 | Safari 홈 화면에서 상태바 뒤까지 타이틀이 그려졌다. 기기 높이는 1,376 CSS 픽셀이었고 Safari 표시 영역은 1,344였다. 아래 32픽셀은 앱 표시 영역 밖에 남았다. |
| Mac Chrome의 Android 휴대폰 모의 | 설치 앱을 전체 화면으로 열어 타이틀, 슬롯, 기지, 상점, 사령부, 전장, 입력과 크기 변경을 확인했다. 별도 복귀 검사에서 양쪽 가로와 같은 배경음의 재개를 확인했다. |

## 갤럭시 v0.3 설치 앱 확인

갤럭시에서 방금 설치한 앱의 등록값은 `standalone`이었다. 같은 시점에 Chrome은 공개 매니페스트에서 `fullscreen`과 `landscape`를 읽었다. 갱신 전에는 홈 아이콘으로 열 때 상태바와 탐색 버튼이 남아 표시 영역이 755×354 CSS 픽셀이었다. **게임 시작**을 누르면 Chrome의 전체 화면 API가 832×384로 넓혔다.

Chrome에 설치 항목 갱신을 요청했다. 설치 버전이 1에서 2로 올라간 뒤 홈 아이콘으로 다시 열었다. 시작 버튼을 누르기 전부터 832×384였고, 상태바와 탐색 버튼은 숨겨졌다. 게임 시작과 홈 화면 복귀 뒤에도 같은 크기를 유지했다. 검사는 이 갤럭시의 90도 가로에서 수행했다.
