# iPhone 상점 크기·거래·마지막 페이지 검증

iPhone 상점의 아이콘, 거래 버튼, 상세창 크기를 일반판 2.0.1에 맞췄다. 배경을 화면 전체에 그리는 배율이 아이콘과 버튼까지 키우고 상세창을 따로 줄이던 경로를 고쳤다. `MenuGridLayout`이 원본 480×320의 배율과 상세창 경계를 계산하고, `Screens`와 `Button`이 그 값을 표시와 터치에 함께 쓴다.

| 912×420 iPhone Air | 일반판 2.0.1 | 수정판 |
| --- | ---: | ---: |
| 기준 아이콘 한 변 | 42pt | Shop·Equip 모두 42pt |
| 상세창 텍스처 | 336×168pt | 336×168pt |
| 상세창 터치 영역 | 270.4×168pt | 270.4×168pt |
| 목록 옆 Buy·Sell 그림과 터치 영역 | 42×74.8pt | 42×74.8pt |

거래 버튼과 확인창에는 원본 좌표를 적용했다. 상세창은 원본 좌표를 출발점으로 삼고 페이지 버튼이나 거래 버튼과 겹치면 안전한 위치로 옮긴다. 912×420에서 첫 상품의 터치 영역은 화면 왼쪽에서 138.5pt, 아래에서 121.8pt에 시작한다. 같은 912×420으로 맞춘 PNG에서 SG-1 상세창 외곽선은 원본보다 24~26pt 위였다. 캡처는 원본 레벨 1과 복원판 레벨 5의 같은 SG-1 선택 상태다. 넓은 배경에 맞춰 조정한 목록의 행·열 간격에도 차이가 남는다.

웨이스트랜드에서 마지막 묶음의 다음 버튼을 누르면 같은 HD 페이지의 첫 묶음으로 돌아가는 현상을 재현했다. `Screens`에서 공통 세션의 실제 페이지가 바뀔 때만 묶음 위치를 바꾸도록 고쳤다. 레벨 22 복원판에서 Weapon 41개·Parts 26개·BOT 6개·Attack 3개·Etc 6개를 각각 6·4·1·1·1 화면으로 확인했다. 일반판은 3·2·1·1·1 화면이었다. ML-K3 상세와 구매 확인도 캡처했다.

SG-1은 원본과 복원판에서 500→250→375 Cr로 바뀌었다. 판매 확인창을 열고 취소하면 일반판은 상세창을 닫은 채 Sell을 남긴다. 원본 캡처에 따라 iPhone 복원판도 이 순서로 동작한다. iPad Air 11인치의 여섯 기지 상점은 이전 후보와 다른 픽셀이 0개였다.

최종 공통 표시·입력 검사와 iPhone GPU 상점·장비·메뉴 검사, iPad 기지 메뉴 검사를 통과했다. 두 시뮬레이터에서 별도 치트 Release가 각각 126조건·2,100프레임을 완료했고 버튼 실패는 0건이었다. 정식 Source Release도 두 시뮬레이터에 설치해 시작 화면을 캡처했다. 표시 크기 수정은 `eb8c788`, 마지막 페이지는 `f51c804`, 판매 확인과 취소 표시는 `262a693`에 있다.
