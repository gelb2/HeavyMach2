# ExperimentalHUD·비전투 메뉴 수정

## 현재 상태

작업 중이다. 공통 HUD와 허브·상점·사령부를 구현했다. 공통CPU5개와ASan/UBSan3개, 최초Native양쪽각8개를통과했다. 시각검수에서는기존Phone지형의대각검정영역이재현되어추가진단중이다. 최종 Apple 빌드·동시 치트·GPU 캡처·측정이 끝나기 전에는 설치·완료로 보고하지 않는다. 기존 iPhone 정식 설치본은3666fc7이다.

## HUD에서 바꾼 것

HP·BOOSTER/SP·EXP·레벨·보유금·왼쪽 무기·오른쪽 무기·퀵5슬롯·메뉴3버튼·레이더·대상정보의11조각과 좌우 무기 선택 패널2개를 공통 C++에서 배치한다. 스타일 선택과 이동은 인게임 메뉴의 HUD 배치에서 한다. 클래식의3조각 배치와 진행 저장은 보존한다. HUD 설정의 새 버전3은 기존 버전1/2를 읽고, 클래식 위치와 Experimental 위치를 함께 보관한다. 적용할 때만 설정 파일을 기록한다.

GameUI_BG 전체 장식판 대신 필요한 표식·수치 바탕·퀵슬롯 테두리·레이더 격자를 같은 원본 텍스처의 UV 영역으로 그린다. 게이지와 숫자는 기존 노드와 값 갱신을 사용한다. HP/SP는 기존 GaugeBack 타일, EXP는 기존 GaugeEXP, 레벨/보유금은 기존 숫자 이미지다. 레이더 마커는 기존 월드 좌표 계산을 그대로 사용한다. 새 숨김·접기·레이더 열닫기를 넣지 않는다.

좌우 무기 선택 패널은 해당 무기 버튼의 이동을 따르고 각 상대 위치를 별도로 저장한다. 실제 보유 아이템의 인벤토리 위치와 ItemCode를 유지한다. 화면 안쪽으로 위치를 보정하고 넘치는 목록은 페이지로 나눈다. 표시와 터치는 같은 변환을 쓴다.

편집 화면은 조각을 직접 끌거나 ‘다음 조각 선택’ 후 고정된 선택 이동 핸들을 끌어 이동한다. 도구에 가려진 조각도 이 경로로 다시 꺼낼 수 있게 한다. 양쪽 패널은 서로 겹치지 않는 이동 핸들을 둔다. 드래그와 그리기 중 저장하지 않는다.

## 검사와 수정 근거

- 초기 공통 검사4개(기존 HUD·화면 입력·Phone Air 동시·iPad 동시)는 통과했다. 이후 변경은 최종 묶음으로 다시 검사한다.
- 새 HUD 검사에서 HP/SP/EXP 변화, 레벨/보유금 숫자 이미지 변화, 레이더 마커 이동, 원본 기능 유지,100회 갱신 중 자원 읽기·조회·텍스트 준비·설정 쓰기 증가0을 확인했다.
- 원본 장비23종을 공통 reader→실제 장착으로 검사했다. SP 최대값320, 막대 최대폭146이다. 파일명만 보고 GaugeHP/Booster가 소비된다고 판단하지 않는다.
- 독립 검토에서 표식 crop 중복, 선택창 핸들 역선택/그림·입력 불일치, 최대 HP 막대 끝 잘림을 발견해 수정했다. 원본의 불투명 픽셀 소유 중복0, 최대 HP 우측 경계, 실제 핸들 입력 회귀를 추가했다.
- 편집 도구가 대상 정보를 덮는 문제와 취소·프로필 전환 후 선택 인덱스가 범위를 벗어나는 위험도 검토에서 발견했다. 도구 배치·선택 회수·인덱스 제한을 수정하고 재진입 검사를 추가한다.
- 최초 Apple 빌드는 QA 보조 함수의 잘못된 PointerPhase 이름으로 실패했고 수정 후 build-for-testing에 성공했다. 첫 GPU 실행 요청은 시뮬레이터 서비스가 기기 목록을 반환하지 않아 앱 실행 전에 실패했다. 이 실패를 앱 합격으로 세지 않는다. 사용자 재개 후 두 기기 목록이 정상으로 돌아왔다.

원본·실패 로그·검사 결과는 `.local/evidence/experimental-hud-implementation-20261114/`에 보존한다. 화면을 확인하지 않은 상태에서 레이더·그래프가 실제 GPU에서도 정상이라고 단정하지 않는다.

## 비전투 메뉴 수정 범위

Phone 원본 삽화 전체를 같은 비율로 표시하고, 남는 좌우·하단은 품목·목록·설명·동작 버튼을 담는 메뉴 영역으로 쓴다. 검은 띠, 끝 픽셀 늘림, 삽화 비율 변형, UIKit 게임 UI로 채우지 않는다. 삽화·강조·시설/길 버튼은 같은 공통 변환으로 묶는다. 상점24칸·인벤토리25칸과 기존 아이템 식별/구매/장착/저장 규칙은 유지한다. 세로 이동을 없애고 긴 사령부 목록·설명·보상은 페이지로 접근하게 한다. iPad의 기존 메뉴 구성과 게임 규칙은 보존한다.

타이틀/스테이지 간 로딩의 HD 일러스트 위쪽 정렬, 가로 배너 잘림, 생명주기 복귀 정지·발열은 각각 기존 TODO로 남긴다. 이번 HUD·비전투 메뉴 수정 완료와 혼동하지 않는다.
