## 전수검사의 범위와 기록 방식

기존1,077함수 본문 목록에 이번 대조 상태를 붙였다. 새 함수 dossier3개와 나머지 미대조를 구분한다. 함수 주소·export 수만으로 완전성을 보장하지 않으며 간접 호출·가상 함수·누락 진입점·런타임 조건도 추적한다. HD1.0.3의 기존1,300함수 자료와 원본 포팅판 관측은 같은 입력 SHA와 조건의 유효한 근거를 재사용한다.

조사는 점프에 한정하지 않는다. [사용자 원문과 TODO](todo.md)의 카메라/표시/입력, 이동/path/충돌/점프/SP, 무기/피해/가시성/적/BOT/생성, 아이템/장비/성장/임무/보상, 전체 메뉴/HUD/전환/자원, 시간/RNG/음향/저장/중단복귀를 모두 포함한다. 각 항목에 원본 함수·호출 조건→복원 소비 코드→발생 커밋→검사/실제 관측→남은 미확인을 연결한다.

기기 차이·출시 버전 차이·복원 회귀를 구분한다. 현재 제품의 HD 공통 게임 규칙·정상 iPad·사용자 저장·원본을 보존한다. 원본 일반판과 다르다는 이유만으로 HD의 무기/SP/저장 규칙을 교체하지 않는다. 기존 상점 수정은 별도로 유지한다.

전체 의미 대조·점프 재현/수정·원본 포팅판과 복원판의 최종 일괄 실행은 미완료다. 현재 완료 범위는 상점 수정 후 브랜치 분리, 원본 동일성/REA 패키지 조사, 기존 본문 목록 재사용, 카메라·월드 갱신·입력3함수의 첫 재대조다.
