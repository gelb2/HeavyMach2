### 이번 작업에서 구현한 범위

- 공유 C++ 복구 모듈은 슬롯 3개의 저장 전체를 읽고 쓴다. 잘못된 코드는 기존 저장을 쓰기 전에 거부한다. 저장을 교체할 때는 실행 환경별 저장소에 복원 전 백업을 남긴다.
- [PWA](../Web/README.md)는 정식판과 치트판의 저장소·캐시를 분리하고, 휴대폰·태블릿·데스크톱에 맞춰 화면과 입력을 연결한다. [Tauri Mac](../Desktop/Tauri/README.md)은 같은 정식 웹 빌드와 복구 모듈을 사용한다.
- [ ] iPhone·iPad의 저장 이동 화면에서 복구코드 복사·붙여넣기·교체 확인을 처음부터 끝까지 누른다. 시뮬레이터의 Apple 런타임은 버튼 입력과 복원·백업·재시작을 검사했다. XCTest가 시뮬레이터를 지정하는 단계에서 실패해 시스템 대화상자까지 이어지는 흐름은 확인해야 한다.
