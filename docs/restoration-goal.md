# HeavyMach2 복원 Goal

2026-11-10 사용자가 아래 목표의 등록과 계속 실행을 지시했다. 실제 대화의 Goal 도구에 active로 등록했다. 이 문서는 등록한 범위와 완료 기준을 기록하며 도구 상태를 대신하지 않는다.

원작이 지원하는 모든 게임 행동을 실제 구현하고 검증할 때까지 작업한다. 현재 TODO뿐 아니라 검증 중 발견하는 오류·누락과 필요한 다음 작업도 조사·계획·구현·검증한다. 단계 보고 후에는 남은 목표에 필요한 다음 작업을 선택해 진행한다. 일부 검사 통과나 예산/도구 한도로 전체 완료를 선언하지 않는다.

완료 판정은 원본 기능·버튼/데이터 ID→실제 소비 코드→자동 동시 조건→정상 앱 행동→원작 포팅판 대조의 연결을 확인한 뒤 한다. 정상/치트 앱의 모든 기능·무기·장비·BOT·임무·맵 이동·캠페인을 포함한다. 원본에 없는 능력·단계·기능을 임의로 만들지 않는다. 사용자의 광고 표시/요청 금지는 유지한다.

기존 스택과 원작의 에셋 reader·조립·저장·음향·시간/난수 절차를 유지한다. HeavyMach2 독립 비공개 저장소에서만 개발하고 다른 게임 파일을 수정하지 않는다. 원본 IPA/ARM은 외부 전송/커밋하지 않는다. 저장·원본·실패 증거를 보존한다. 브랜치는 작업→develop→main을 지킨다.

먼저 iPhone 가로·iPad 세로의 시뮬레이터에서 검증한다. 실기기 빌드/설치는 기존 검증 우선 지시를 따른다. 그 뒤 기존 복원 계획의 추가 방향·플랫폼으로 진행한다. 오류 수정·필요한 독립 검토·문서/TODO·기존 비공개 사이트 보고·커밋을 수행한다. 쓰지 않는 이전 빌드는 사용 여부와 재생성 근거를 확인해 정리한다.

실제 진행은 [TODO](todo.md)와 단계별 검증 근거에서 확인한다. 중단·재개·사용량 한도와 목표 달성을 구분한다.

사용자 후속 확인: 완료 후 사용자가 직접 플레이·테스트할 수 있어야 한다. 정상 앱과 동시 치트 앱을 실제 실행 가능한 빌드로 제공하고 실행 위치·사용 방법·검증 범위를 보고한다. 정상 앱의 수동 플레이뿐 아니라 치트 앱의 자동 검증 결과 확인과 조건 선택/직접 조작도 준비한다. 사용자가 조작한 실행을 자동 회귀 PASS와 섞지 않는다.
