# iPad 정식 Release 설치와 사용자 플레이 확인

2026-11-11. 작업 브랜치 `feat/reference-ports`의 `4980818`을 기준으로 정식 앱 `HeavyMach2Source`를 Release 구성으로 빌드해 실제 iPad에 설치했다. 게임 소스 변경은 없었다. CLI의 인증서 서명은 `errSecInternalComponent`로 실패했으며, Xcode에서 같은 프로젝트의 Release 빌드와 서명을 완료했다. 설치한 앱의 `codesign --verify --strict`도 통과했다.

## 직접 확인한 범위

- 준비 자원 1,479개와 앱 번들에 담긴 1,479개의 파일명·SHA-256이 모두 일치했다.
- Scene 설정과 iPad 세로 방향 설정이 패키지에 포함됐다.
- 무료 개발 앱 3개 한도로 설치가 거절됐다. HM2 HD 포팅판의 데이터 컨테이너 28개 파일, 59,227,643바이트를 로컬에 백업하고 파일별 해시를 남긴 뒤 포팅판을 정식 앱으로 교체했다. 헤비멕1·맥디펜스 앱은 유지했다.
- 앞서 보존한 정식판 저장 28,204바이트를 복구했다. 기기에서 다시 복사한 파일이 백업과 바이트 단위로 일치했다.
- 정식 앱 실행과 프로세스 유지, Device Hub의 실제 iPad 타이틀 표시를 확인했다. 설치 전후 크래시 목록은 같았다. 이전의 2026-11-10 시작 오류 두 건은 보존했다.

이 검사는 설치·시작·타이틀 표시의 결과다. 전체 게임의 무결함이나 원작 전체 동등성을 판정하지 않는다. 앱 아이콘은 이 설치 시점에 연결하지 않았으며 후속 작업으로 진행한다.

## 사용자 직접 플레이 관측

사용자 제공 원문:

> 내가 첫 미션 근처에서 전투하고 움직이고 손가락으로 경로 여러개 그리는 것 되었다. 퀘스트 받고 퀘스트 성공한거도 내가 한 시점에선 되었고.

첫 미션 근처의 이동·전투·여러 경로 입력, 퀘스트 수락과 성공은 사용자가 실제 iPad에서 확인한 결과로 기록한다. 이는 자동검사 결과가 아니며 다른 임무나 최종 캠페인까지 확인한 것으로 확대하지 않는다.

스카이베이스 진입 후 퀘스트 완수와 이미 수집 수량을 충족한 퀘스트의 수락 후 완수 처리를 사용자가 확인했다. 원작과 같은 정상 동작이라는 판단도 사용자 확인으로 기록한다. 스카이베이스 주변 이동·전투·아이템 획득·스킬 사용 중 크래시를 아직 발견하지 않았다는 관측은 해당 플레이 시점의 결과다. 자동검사·전체 캠페인 확인으로 취급하지 않으며, 별도 제보된 아이템 지급 의심과 E-10 효과음·토스트 누락은 미해결로 유지한다.

## 보존한 근거

로컬 `.local/evidence/ipad-release-20261111/`에 빌드·서명 오류, 설치 실패와 성공, 포팅판 데이터 백업과 해시, 정식판 저장 복구, 패키지 명세, 실행·프로세스·크래시 목록과 `result.json`을 보존했다. 원본 IPA·앱 빌드·사용자 저장·기기 식별자·서명 자료는 커밋하지 않는다.

Xcode가 자동 변경한 로컬 팀 설정·프로젝트/스킴 정규화는 근거를 보존하고 작업 시작 전 내용으로 복구했다. 실패한 unsigned 앱과 해당 dSYM은 성공한 signed Release 후보로 대체돼 삭제했으며, 실제 설치한 signed 앱·dSYM·로그·저장은 유지했다.
