# 보행 검증 뒤 전투 복원 계획

2026-11-10 사용자 지시: 검증에서 발견한 차이·오류를 고치고, 다음 단계 계획을 기록한 뒤 진행한다.

## 직전 검증과 수정

보행·조준·터치 경로·지형 충돌을 같은 C++ 코어에 연결했다. C++13개, iPhone/iPad의 GPU3개+실제 터치UI1개가 각각 통과했다. 두 기기의 검사 시간은 약7.256초 겹쳤다. 원본 실행과의 보행 정밀 대조·정상 게임 전체는 미완료다. 원본 수식의 첫40tick은 정적 분석에서 도출한 값과 대조했다.

발을 교대하는 프레임의 중복 진행, 발 각도 snap 검사 순서, 원작에 없는 진입 phase2 처리, 다른 touch ID 종료 때 포인터 유지, 실제 UIView의 다중터치 미전달을 고쳤다. 원본에서 실제 그림에 소비되지 않는 scale 값을 그림 확대에 적용하지 않았다. 숫자 변환 API의 낮은 iOS 지원 문제와 UI 검사 UIKit 링크 누락도 고쳤다. 원본 지형 1354개 선분과 Stage01_01의 고정 벽 접촉점을 검사했다. 상세 결과는 [보행 기록](locomotion-restoration-20261110.md)에 남긴다.

## 다음 범위와 순서

1. **공통 WeaponInfo 소비:** 원본 GlobalInfo::openWeaponInfo0x14bc4가 읽는 문자열 ID·무기 분류·피해·공격 범위·발사 수·간격·재장전·속도·명중률·그림·효과·음원 참조를 복원한다. 원본 ShtRng의2배 변환과 signed16/unsigned8 좁힘을 보존한다. 기본 MG-16/ML-1을 포함한213개 원본 행을 검사한다. 숫자/문자열을 유닛별 C++ 정의로 복제하지 않는다.
2. **controller와 포구:** 무기 파츠에 원본 WeaponController를 연결하는 절차, getMuzzlePos·소켓·반전·각, reload/fire 시각·탄 수·좌우 선택을 복원한다. 게임 상태가 발사를 허용해야만 실제 공격 사건이 발생하게 한다. 치트에서 결과값을 강제로 성공시키지 않는다.
3. **기관총과 미사일 분리:** 원본 type0 기관총은 이동 GobBullet을 생성하지 않고 지정 표적의 직접 피해와 포구/도착점 효과를 사용한다. 미사일은 원본 GobBullet 생성·이동·종료·폭발·피해 경로를 따로 확인해 연결한다. 모든 무기를 같은 직선탄으로 대체하지 않는다.
4. **실제 적·피해·보상:** 원본 맵 spawner 수명과 적 생성 조건을 조사한 뒤 실제 적·선택·공격 후보를 연결한다. 모든 spawner를 로드 시점에 한꺼번에 적으로 만드는 구현을 넣지 않는다. HP·격파·보상·EXP·임무는 원본 소비 경로를 순서대로 검증한다.
5. **음향과 수명:** 발사 음원 참조·원본 준비/캐시 시점·OpenAL 재생 요청 순서를 연결한다. 사격마다 파일 쓰기·PCM 재해석·context/source 생성을 추가하지 않는다. 음향 미구현 상태를 전체 발사 기능 완료로 보고하지 않는다.

## 통과 기준

- 같은 원본 데이터와 C++ 코어를 Source·Validation 양쪽 앱에서 사용한다. 새 유닛도 같은 경로를 사용한다.
- 기본 좌우 무기의 포구 좌표·반전·대상·허용 상태·발사 간격·탄 수·재장전·피해 사건을 고정 조건으로 검사한다. 서로 다른 시간 경계의 안/같음/밖을 포함한다.
- 한 인스턴스에서 이동·조준·양쪽 공격·피격·성장 조건을 함께 검증하고, 배타적인 메뉴/저장 조건은 독립 인스턴스로 병렬 검사한다.
- 예열 후 반복 공격에서 자원 재읽기·텍스처/음향 객체 생성·실제 파일 쓰기를 계측한다. 계측되지 않은 것을0으로 보고하지 않는다.
- iPhone 가로·iPad 세로에서 실제 화면·입력·결과를 확인한다. 포팅판의 시뮬레이터 정상동작 확인 전 실기기 설치 금지를 유지한다.
- 검사에서 드러난 차이는 수정하고 같은 검사를 다시 실행한다. 전체 전투가 끝나기 전에도 데이터 consumer·controller·표시·음향 각각의 완료 범위를 구분한다.

이 계획을 기록한 뒤 [WeaponInfo 소비와 포구 계산](weapon-data-restoration-20261110.md)을 구현·검사했다. 다음은 controller의 재장전·발사 시각·탄 수·난수·반동 연결이다. 기관총/미사일 발사·피해·보상·음향 전체는 아직 완료하지 않았다.
