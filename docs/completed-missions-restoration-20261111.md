# 완료 임무 보상과 결과창 복원

2026-11-11. 사령부에 들어가도 완료 임무의 보상이 지급되지 않던 문제를 수정했다. 원본 HD 1.0.3의 수락 순서·현재 기지·완료 조건에 따라 한 건씩 자동 보상하고 결과창을 표시한다. OK를 누르면 다음 완료 임무를 처리하며, 마지막 창을 닫은 다음 게임 tick에서 임무 목록을 표시한다.

## 바뀐 동작

수정 전에는 완료 조건을 준비한 저장으로 사령부에 들어가도 금액이 500Cr에 머물렀다. 수정 후 같은 조건에서 첫 임무 M002010의 80Cr·EXP200을 지급하고, OK를 누르면 M001010의 100Cr·EXP200·수리 아이템3개를 지급한다. 금액은500→580→680Cr, EXP는0→200→400, 레벨은0→1로 바뀐다. 미완료 임무와 다른 기지에서 보고해야 하는 임무는 남는다.

결과창은 원본 MissionCompletedBG·OK 버튼·보상 아이콘과 글꼴 설정을 공통 GPU UI로 표시한다. 새 플랫폼 버튼이나 별도 보상 계산기를 만들지 않았다. 원본처럼 결과창 바깥의 EXIT와 랭킹 입력은 유지한다. 랭킹은 사용자 지시에 따라 한국어 이용 불가 알림을 표시한다.

보상과 OK 입력은 저장 파일을 쓰지 않는다. 원본 기지 복귀 시점에 저장하며, 정상 Source 앱을 종료하고 같은 검사 저장으로 다시 실행했을 때 보상을 중복 지급하지 않는지 확인했다. 자동 검사용 저장은 별도 UUID 경로에 만들고 일반 사용자 저장은 변경하지 않는다.

## 원본과 연결한 규칙

HD 실행파일을 로컬 REA·Ghidra로 분석한 결과다. 원본 개발 소스를 확보한 것은 아니다. 이번 단계에서 원본 포팅판의 같은 결과창을 직접 실행해 비교하지는 않았다.

| 원본 소비자 | 복원한 규칙 |
|---|---|
| refreshCompletedMission 0x269ac | 기존 창 제거, 수락 순서와 현재 기지로 첫 적격 임무 하나 선택 |
| completeMission 0x279a8 | SFX11→창·제목·OK→보상 표시와 적용→임무 완료 |
| handleButton 0x25a2c, ID5007 | 다음 결과창을 동기 갱신한 뒤 클릭음0. 별도 저장 없음 |
| Command.tick 0x26558 | 한 tick에 상태 한 번 소비. 마지막 OK 다음 tick에 목록 갱신 |
| ID5004 수락 | 성공·실패·선택 없음 모두 다음 tick 목록 갱신. 수락 즉시 자동 보상하지 않음 |
| QobManager.onTap 0x3a23c | 뒤에 등록한 버튼부터 입력 판정. 결과창을 전역 입력 차단 창으로 바꾸지 않음 |

결과창 중심은HD 논리좌표(384,512), 배경은512×256, 자식은원본 layer9다. 아이템 아이콘은 보상 action의 원본 ID를 사용한다. 인벤토리 부족으로 아이템 일부만 들어가는 원본 경로도 뒤의 다른 보상·임무 완료를 계속한다.

## 검사 중 발견해 고친 사항

임무를 수락한 직후 다음 tick 전에는 원본처럼 기존 목록이 화면에 남는다. 이때 입력만 새 목록 인덱스를 사용해 두 번째 행의 선택이 무시되는 문제를 독립 검토에서 발견했다. 화면에 표시한 목록의 ID와 인덱스로 입력을 처리하도록 고쳤다. 같은 실제 Screens 입력에서 실패 후 통과를 기록했다.

초기 동시 검사 캡처는 완료창 오브젝트가 있어도 전환문에 가려졌다. 이 캡처를 창이 보인 근거로 사용하지 않는다. 검사 입력을 실제 문이 열린 뒤에 보내도록 바꾸고 문 그림이 없는 캡처를 요구했다. 제품 입력에 문 상태 제한을 추가하지 않았다.

초기 검사에서 수리 아이템의 기존5개를 빠뜨린 기대값과, 화면 명령으로 변환된 이미지의 크기를 잘못 읽은 검사도 수정했다. 실패 로그는 보존했다. 최종 검사에서는 기존5개에 보상3개를 더한8개와 실제 출력 사각형을 확인한다.

## 남은 작업과 다음 순서

1. HD 원본 포팅판에서 같은 완료 임무·OK·EXIT·재시작을 실행해 결과와 화면을 대조한다. 포팅판 저장은 별도 백업하고 판본이 다른 저장을 섞지 않는다.
2. 아직 빠진 사령부에서 임무 선택 시 상세창이 펼쳐지는 애니메이션을 원본 함수·실행에서 확인하고 공통 UI에 연결한다. 이번 결과창에는 원본에 없는 펼침 효과를 추가하지 않는다.
3. 전체60임무·캠페인 진행, 하체23종, 원본 게임오버·중단/복귀, 기기별 표시·입력 대조를 이어간다.

iOS·iPadOS 검증을 우선한다. 실기기 설치 전달, 다른 플랫폼 확장, develop/main 릴리스는 현재 보류 상태다. 이번 부분 구현과 회귀 통과를 전체 게임 복원 완료로 보고하지 않는다.
