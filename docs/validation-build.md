# 치트 앱과 동시 검증

2026-11-10 사용자 지정: 치트 앱은 경험치·레벨·아이템·진척도의 허들을 건너뛰고, 게임에서 지원하는 모든 기능과 버튼을 여러 조건 아래 동시에 검증하기 위한 앱이다. 기능을 하나씩 켜 보고 종료하는 검사만으로 완료하지 않는다.

## 구현 기준

- 일반·치트 앱은 같은 C++ 코어·원작 데이터·렌더·음향·저장 경로를 쓴다. 치트는 시작 조건을 준비한다. 명중·획득·경험치 지급·레벨업·강화·임무 성공의 결과를 강제로 만들어 통과시키지 않는다.
- 기능 목록은 실제 원본의 메뉴·버튼 ID·장비·스킬·전투·진행·저장 소비 경로에서 작성한다. 테이블에 없는 코드 생성 버튼도 포함한다. UI가 보였다는 사실과 버튼을 눌러 실제 효과가 발생했다는 결과를 구분한다.
- 한 전투에 무기·파츠·아이템·성장·임무 조건을 함께 준비한다. 이동·조준·발사·피격·획득·경험치 증가·레벨업·효과음·HUD를 함께 동작시키며 결과와 프레임·메모리·자원 수명을 검사한다.
- 서로 배타적인 원작 화면·저장 조건은 독립 인스턴스로 병렬 검사한다. 장비창에서 원작이 전투를 멈추면 그 규칙을 바꾸지 않는다. 별도 전투 인스턴스를 동시에 실행하고, 각 인스턴스에서 메뉴·장착·저장·전투 결과를 확인한다.
- 실행마다 simulator/process·게임 상태·일반/치트 저장·seed·입력·출력 로그·xcresult를 분리한다. 같은 시뮬레이터 화면이나 저장을 여러 실행이 동시에 조작하지 않는다. 하나의 빌드 산출물은 읽기 전용으로 재사용한다.
- 개별 경계 검사, 복합 조건의 동시 실행, 전체 기능/버튼 목록의 검증 여부를 함께 남긴다. 전수 목록에서 미구현·미검사 항목을 숨기지 않는다. 명령·검사가 실제로 겹쳐 실행됐는지도 기록한다.

## 현재 구현한 범위

`HeavyMach2Source`와 `HeavyMach2Validation`은 같은 소스·자원을 사용하는 보행 단계 타깃이다. bundle ID는 각각 `com.gelb2.heavymach2.restored`, `com.gelb2.heavymach2.validation`이다. [보행 구현](locomotion-restoration-20261110.md)에서 Source는 Stage01_01 지형의 기본 장비 Player를 실제 터치로 이동시킨다. Validation은 보행 Player와 다른 장비의 명시 조준 사례를 함께 표시한다. 이전 네 E_Tank_01 조립 사례는 별도 회귀 검사로 유지한다. 전투·레벨업·아이템·진척도 치트는 아직 구현하지 않았다.

검증 소스는 원본 정의를 읽는 C++ 코어를 사용한다. 실제 보행·별도 조준·지형을 함께 갱신하고 pause와 GPU 출력·픽셀·텍스처/컨텍스트 재사용을 검사한다. 독립 iPhone/iPad 인스턴스에서 실제 UIKit 터치도 병렬 검사한다. 무기 데이터·포구 계산은 소비 검사이며 실제 발사 검사는 아니다. 이것은 위 전체 게임 치트 요구의 완료가 아니다.

`tools/test_apple_parallel.py`는 이미 빌드한 Apple 검사를 서로 다른 iPhone·iPad 시뮬레이터에서 동시에 실행한다. 각 실행의 로그·xcresult와 관측한 검사 시간 겹침을 저장한다. 실제 실행 근거는 [첫 구현 기록](initial-source-restoration-20261110.md)에 있다.

## 전체 기능 개발 계획

[전체 기능 치트 앱 개발·검증 계획](full-validation-development-plan-20261110.md)에 확인한 HD 데이터 목록, 추가할 게임 기능·자동 실행기, 복합/병렬 검사, 오류 수정 절차와 완료 기준을 기록했다. ItemInfo255개·무기213개·맵43개·기체78개·임무60개·기지 Button행27개는 목록 확인 수다. 코드 생성 버튼까지 포함한 전체 기능 수는 첫 조사 단계에서 확정한다.

## 다음 연결

먼저 실제 Player의 보행·조준·맵 충돌·전투·UI·성장·저장·음향을 원본 함수와 연결한다. 해당 기능을 구현할 때마다 전체 기능 목록과 복합 시나리오에 추가한다. 예를 들어 레벨업 직전 경험치·모든 장비 접근·아이템 재고를 함께 준비한 뒤 실제 전투의 경험치 획득으로 레벨업하고, 같은 시간에 다른 인스턴스의 장착·임무·저장 검사를 실행한다. 구체적인 XP 임계·장비 ID·저장 필드는 원작 조사로 정하며 HM1/MD 값을 대입하지 않는다.
