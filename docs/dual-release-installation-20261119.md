# iPhone·iPad 실기기 Release 검증 — 2026-11-19

`f8e82d8`에서 검증한 `HeavyMach2Source`의 Release를 같은 앱 ID로 iPhone Air와 iPad Air 13인치(M2)에 업데이트했다. 두 기기는 27.2.1이다. 동일한 arm64 번들의 서명과 두 기기의 프로비저닝을 확인했다. 준비 자원 1,550개는 번들 파일과 바이트가 일치했다. 개발 프로파일의 만료는 11월 20일 20:15 한국시간이다.

설치 전에 앱 데이터 전체를 기기별로 백업했다. 앱을 열기 전 다시 받아 저장 파일 각각 28,204바이트와 iPhone HUD 43바이트를 비교했다. 설치 전후 내용이 같았다. 두 기기에서 타이틀, 기존 슬롯, 웨이스트랜드 기지가 열렸다.

| 항목 | 두 실기기의 확인 범위 |
| --- | --- |
| 상점 | 다음 상품 페이지와 상세가 열리고 인벤토리가 표시됐다. iPhone은 인벤토리 다음 페이지도 열었다. 거래는 발생하지 않았다. |
| Skyway | 웨이스트랜드 기지 출구로 Skyway 04에 들어갔다. 경로 입력으로 메크가 이동했고 기지로 돌아오는 포털이 작동했다. |
| 점프 | 경로를 바꾸고 더블탭하자 메크가 빠르게 움직이고 부스터 게이지가 줄었다. Device Hub로 넣은 실기기 입력과 화면을 확인했다. |
| 저장 | 두 기기의 사용 슬롯 모두 웨이스트랜드 기지로 복귀했다. 플레이 중 각각 XP 200을 얻었고 레벨·소지금·HP가 같았다. iPhone HUD 파일도 동일했다. |

검사 직후 기기 충돌 로그에서 해당 앱 파일이 0개였다. 실기기 화면 녹화 기능이 지원되지 않아 배경과 배율의 프레임별 수치, 상점 행 수를 바꾸는 창 크기 회귀는 앞선 시뮬레이터 검사 범위로 남긴다. 실기기에서 장시간 플레이와 더블탭 실패율은 측정하지 않았다.

iPhone 시뮬레이터의 같은 복원 후보에서 기본 목록·상품 상세·끝 페이지·구매 확인을 별도 캡처했다. 상품 상세에서 실기기와 같은 BUY 가림이 보였다. 네 시험 화면은 가로·세로 드래그 후 목록 오프셋과 버튼 위치가 같았다. 이 수치는 복원판 912×420 시험 조건의 관측이다.

수정 전 원본 일반판 및 iPhone 포팅판의 상점을 다시 캡처한다. 가로·세로 드래그가 목록 위치를 움직이는지, 다음 페이지나 아이템 드래그로만 반응하는지 상태별로 기록한다. 모든 상품·인벤토리·장비/BOT 칸의 원본 픽셀 크기, 실제 화면 크기·간격·좌표와 버튼 화상을 측정한다. 상세창, BUY·SELL·확인·취소·하단 탭의 평상시·선택·비활성 표시와 터치 영역도 같은 조건에서 비교한다.
