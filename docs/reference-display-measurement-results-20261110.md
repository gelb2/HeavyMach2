HUD 외곽은 케이블·원형 버튼·미니맵 등 튀어나온 요소와 내부 빈 공간을 포함하는 사각형이다. 실제 불투명 가림 면적이 아니다. 상단 HP·부스터·타깃 표시는 하단 HUD 외곽에 포함하지 않았다. 숫자 높이는 화면에 그려진 잉크 경계이며 폰트 크기 설정값이 아니다.

일반판 퀵슬롯 그림은 약 32×32 내부 단위다. HD는 아이콘을 감싼 금속 프레임 약 48×50, 안쪽 그림 약 33×33으로 분리해 기록했다. 서로 다른 프레임 경계를 같은 요소라고 보고 단순 배율을 산출하지 않는다. 전체 29개 측정 사각형과 원본 좌표·해시·화면 점유율·호스트 논리 크기는 [측정 데이터](evidence/reference-display-measurements-20261110.json)에 있다.

## 확인한 차이와 해석 한계

HD HUD는 일반판 HUD의 일괄 확대와 다르다. 미니맵·메뉴·상태 막대를 재배치했고 각 요소의 크기 비율도 서로 다르다. 측정 장면에서 HD의 메크와 붉은 적은 화면 폭 점유율이 일반판과 비슷하지만 세로 점유율은 더 작았다. 가로/세로 화면비와 게임 내부 좌표가 다르므로 이것만으로 동일 줌이나 월드 시야의 증가 배수를 확정할 수 없다.

두 전투 캡처는 같은 첫 전장·레벨1·500 Cr 표시지만 카메라 중심·장비 ID·줌 수치·애니메이션 프레임을 완전히 일치시키지 못했다. 붉은 차량은 화면에 나타난 E_Tank_01과 외형상 대응하나 측정한 개체의 내부 ID를 직접 읽은 것은 아니다.

다른 장면의 HD 메크는 약 51×44 내부 단위였다. 지형이 검게 사라진 일반판 캡처에서는 약 42×40이었다. 후자는 정상 렌더링 기준에서 제외한다. 방향·애니메이션·줌·오류의 영향을 분리하지 못했으므로 관측값을 한 기기의 고정 크기로 쓰지 않는다. HD에서 포신이 있는 다른 궤도 차량도 약 75×50 내부 단위로 별도 측정했으며 유닛 ID는 미확인이다.
