# 실행·저장·사운드 보존 기준

2026-11-09 사용자 지시를 포팅 비교 앱과 후속 소스 복원판에 함께 적용한다.

- 사격·총알·명중 이벤트마다 원작에 없는 DB 또는 파일 쓰기를 추가하지 않는다. 원작 저장 호출 위치와 실제 파일 쓰기 시점을 먼저 확인한다.
- 효과음을 재생할 때마다 오디오 장치나 컨텍스트를 생성·폐기하지 않는다. 원작의 초기화·재생·중단·종료 순서와 자원 수명을 보존한다.
- 원작 재생 호출을 임의 작업 대기열·타이머·프레임 후처리로 미루지 않는다. 호환 API에서 실제 출력 API까지 이어지는 호출 경로를 기록한다.
- 계측은 별도 실행에서만 켠다. 일반 실행의 프레임·사격·오디오 경로에 반복적인 디스크 로그를 넣지 않는다. 계측 중 시간과 일반 실행의 성능 수치를 구분한다.
- 원작 일반판과 HD판 각각에서 연속 사격·동시 효과음·장면 전환·저장·중단/재개를 검사한다. 한 판본의 결과를 다른 판본의 근거로 쓰지 않는다.

포팅판의 게임 계산은 원본 ARM 바이너리가 수행한다. 소스 복원판은 별도 C++ 공통 코어를 사용한다. 두 앱의 [현행 작업 순서](validation-build.md#작업-순서)를 따른다. 호환 계층의 함수 구현과 실제 호출 결과를 함께 검사하며, 원작 코드 실행만으로 호스트의 저장·음향·그래픽 동작이 검증됐다고 간주하지 않는다.

## 남은 실행 증거

- [ ] 일반판 연속 사격 중 원작 저장 호출·파일 쓰기·오디오 생성/해제·재생 호출 관측.
- [ ] HD판의 같은 항목 관측.
- [ ] 실제 기기에서 일반 실행의 프레임 간격과 음향 지연 검사.
- [ ] 저장·불러오기·중단/재개 후 자원 수명과 소리 복구 검사.

이 항목은 타이틀이나 메뉴 표시 성공만으로 완료 처리하지 않는다.

## 2026-11-09 시뮬레이터 중간 관측

- 직접 확인: HD판 이름 입력, 새 저장 슬롯 생성, 첫 임무 수락, 전장 진입, 적 이동, 필드 클릭 후 플레이어 이동.
- 사용자 관측: 시뮬레이터에서 트랙패드로 클릭했을 때 몇몇 기능이 동작한다고 확인했다. 구체적인 기능별 통과로 확대하지 않는다.
- HD판 실행 로그에서 오디오 컨텍스트 생성 1회를 확인했다. 전투 중 재생 호출과 쓰기 시점의 대조는 아직 끝나지 않았다.
- 일반판은 업로드 전 CPU 픽셀, GPU 업로드 직후 픽셀, 첫 그리기 직전 GPU 픽셀이 일치했다. 배경과 로고 두 이미지에서 확인했다. 첫 그리기의 viewport가 0×0으로 관측되어 초기화와 화면 출력 컨텍스트를 추적 중이다.
- 두 판본의 시뮬레이터 정상동작 확인 전에는 실기기 빌드·설치를 하지 않는다.
