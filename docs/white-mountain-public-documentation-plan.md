# 화이트마운틴과 미등장 콘텐츠의 설명·이미지 보강 계획

화이트마운틴의 진입 방법과 설원에서 만날 적, 새로 얻을 무기·공습·BOT을 플레이 순서로 소개한다. 조사한 원작 판본에서 확인한 그림·데이터와 내가 추가하도록 지시한 등장·입수 조건을 항목마다 함께 적는다. 원작 쪽은 판본과 확인 범위를 명시한다. [원작 자료 조사](original-unused-content-20261119.md) · [구현과 실행 기록](white-mountain-implementation-20261119.md)

## 설명과 화면

| 항목 | 본문에 적을 내용 | 사용할 게임 화면 |
| --- | --- | --- |
| 화이트마운틴 기지와 설원 6곳 | 원작에 남아 있던 기지 그림·시설 UI와 HD 1.0.0의 설원 그림을 소개한다. Desert 01에서 기지로 들어가 SnowPass로 나가는 길, 설원 전장 연결과 새 충돌 경계를 설명한다. | Desert 01의 진입 지점, 화이트마운틴 기지 출구, 첫 설원 전장. 기지 사진에는 어느 버튼이 어디로 이어지는지 표시한다. |
| 보스 05~08과 의뢰 | 원작 보스 데이터와 새 의뢰·보상 조건을 대조한다. 의뢰 수락 후 지정 전장 안쪽에서 접근하면 출현하고, 격파 결과를 사령부에 보고하는 순서를 적는다. | 사령부의 수락 화면, 출현 직후 보스전, 완료 보고 화면. 기존 [Boss 05 캡처](public/media/gameplay-20261121/snow-boss.png)는 iPhone 시뮬레이터 치트판으로 표기한다. |
| 설원의 일반 적 | 원작에 남은 비행체·포탑·전차의 정의를 확인하고, 설원에 새로 넣은 배치와 기존 무기 유형을 사용해 보완한 비행체 사격을 설명한다. | 비행체가 실제 발사하는 프레임과 포탑·전차가 배치된 전장. 적 이름과 맵 이름을 붙인다. |
| 저격총 4종과 LS 무기 21종 | 원작의 장착 레벨·발사 정의를 보존한 범위와 새 상점·드롭 경로를 나란히 적는다. 장비군마다 예시 한 종을 들어 어디서 어떻게 얻는지 보여 준다. | 상점 또는 실제 드롭, 같은 무기를 장착한 전투 화면. 이름과 입수 조건이 보이는 장면을 고른다. |
| 레이저 공습 | 원작에 있는 효과·가격과 복원판에서 연결한 특수공격 진열·구매·퀵 슬롯 사용을 설명한다. 공습 피해 보정은 별도 설명으로 연결한다. | 상점 특수공격 탭, 퀵 슬롯 등록, 전장에서의 공습. [공습과 구매 검증](campaign-and-ipad-followup-20261120.md) |
| 수집형 BOT 3종 | Picker D~F의 원작 정의와 플레이에서 사용하는 경로를 적는다. 전리품을 주워 플레이어에게 전달하는 동작을 보여 준다. | BOT 장착 화면, 전리품 접근과 전달 직후 인벤토리. 같은 수집 사례의 전후 화면을 고른다. |

화염방사기·근접 공격·EMP·방어형 BOT은 현행 기능 소개의 남은 작업에 둔다. [후속 범위](public/features.md#남은-작업)

## 게재 위치와 확인

1. 한·영 README의 기여 섹션에서 화이트마운틴 단락에 대표 캡처 한 장과 설원 진입 설명을 붙인다. 무기와 BOT 단락은 각 상세 항목으로 연결한다.
2. [기능 소개](public/features.md)의 화이트마운틴과 무기·적·BOT 섹션에 위 표의 조건을 풀어 쓰고, 관련 화면 옆에 설명을 붙인다. 현재 공개 빌드의 등장·입수 조건을 [캠페인 데이터](../Resources/Campaign)와 대조한다.
3. [플레이 갤러리](public/gameplay-gallery.md)에 기지 진입, 보스전, 아이템 입수·사용 순서로 이미지를 배치한다. 기존 자료로 보이는 장면을 먼저 쓰고, 부족한 장면을 캡처한다. 각 캡션에는 기기, 정식판·치트판, 맵, 화면에서 확인할 동작을 적는다.
4. 공개하기 전에 한·영 README의 캡션과 링크 대상을 대조한다. 원작의 그림·데이터와 복원판의 실행 장면을 같은 것으로 설명하는 문장이 없는지 확인하고, 실제 공개 페이지에서 모든 이미지와 연결 문서를 연다.
